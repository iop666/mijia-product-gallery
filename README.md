# 米家产品示例图库（mijia-product-gallery）

一个 Windows 原生的米家产品素材图库与产品图管理器。基于米家百科公开产品库，把 10,000+ 个米家/生态链产品的官方示例样图集中到一个快速、离线、可管理的桌面应用里：浏览、搜索、筛选、收藏、导出，一应俱全。

采用 WinUI 3 原生开发，深色 / 浅色 / 灰色三主题，高 DPI 与无障碍支持，全部数据保存在本地。

---

## 功能特性

### 浏览

- **产品图库**：全部产品的官方示例样图，卡片网格居中排列
- **两种浏览模式**：
  - 分页模式（默认）：页码直接输入跳转，每页数量 9~140 可配（默认 21）
  - 连续滚动模式：瀑布式连续浏览，虚拟化渲染，全库流畅滚动
- **随机浏览**：一键随机换一批，发现库中被忽略的产品
- **搜索**：关键字实时搜索（防抖），支持搜索历史与建议
- **筛选**：大类、品牌、在架状态、有无图片、使用情况、更新时间多维组合
- **排序**：名称 / 型号 / 使用次数 / 最近使用 / 更新时间 / 添加时间，正序倒序

### 产品操作

- **详情**：左键点击卡片查看产品信息
- **复制**：右键菜单复制图片 / 产品名称 / 型号 / 品牌 / 完整信息到剪贴板
- **拖拽**：左键按住卡片直接把原图拖到资源管理器、Photoshop、PowerPoint 等任意支持图片的位置
- **收藏**：星标加入默认收藏；或通过"加入收藏"菜单把同一产品加入多个自定义收藏夹

### 收藏与收藏夹

- 默认收藏（星标）+ 自定义收藏夹（可创建、重命名、删除）
- 收藏夹视图：独立浏览每个收藏夹内的产品
- **一键导出 ZIP**：
  - 两种命名方式：产品 ID / Model，或设备名称
  - 非法文件名自动安全化、重名自动追加序号、缺失图片计入失败明细
  - 流式打包（不占额外内存）、进度显示、随时取消
  - 只读取数据，不修改数据库与原图

### 数据与统计

- **最近使用**：按最新使用时间回看操作过的产品
- **使用统计**：今日 / 本周 / 本月 / 累计使用次数、最常使用产品排行
- **图库概览**：产品总数、有图 / 无图、官网已移除数量、各大类产品数量
- **后台增量同步**：自动发现米家百科的新增 / 下架 / 换图 / 归类变化 / ID 复用，同步不覆盖任何用户数据（收藏、使用记录、收藏夹）
- **同步实时进度**：同步中心实时显示当前阶段、计数百分比、已用与剩余时间；同步带来数据变化后筛选面板自动刷新
- **备份与恢复**：一键备份数据库、从备份恢复，迁移与恢复前自动再备份

### 界面与体验

- 浅色 / 深色 / 灰色三主题实时切换，无需重启
- 高 DPI（200% 及以上）清晰渲染
- 完整键盘操作与无障碍标注（详见下方操作指南）
- 图库为空 / 收藏夹为空等状态均有明确引导

## 快速上手

### 系统要求

- Windows 10 2004（19041）或更高版本
- x64 架构

### 首次启动

1. 启动应用后阅读并同意使用条款
2. 图库为空时应用**不进入主界面**，而是打开一个控制台加载窗口（cmd 样式），自动完成首次数据获取：
   - **种子包导入**（推荐）：检测到 `seed-<日期>.zip` 初始数据包时离线导入，显示图片/产品写入计数
   - **在线初始化**：无种子包时直接从米家百科拉取，显示阶段进度、已用时间与剩余时间（预计获取产品 10,000+ 个、示例样图 10,000+ 张，约 5-15 分钟，取决于网速）
   - 加载窗口内实时显示获取进度与当前状态；**请勿关闭该窗口**（关闭会中止本次初始化，重新启动应用可继续）
3. 加载完成后自动进入图库；若初始化失败（如无网络且无种子包），会回退到应用内初始化页提供重试 / 选择种子包入口

### 数据存储位置

所有运行数据统一保存在**应用目录下的 `Data\` 文件夹**内（安装版为安装目录，便携版为解压目录），不写入任何系统用户目录：

```
<应用目录>\
└─ Data\
   ├─ Database\gallery.db    产品库（SQLite）
   ├─ Images\                原图
   ├─ Thumbnails\            缩略图缓存
   ├─ Backups\               数据库备份
   ├─ Logs\                  日志
   ├─ Cache\                 缓存
   ├─ State\                 运行状态
   └─ Seed\                  种子包
```

- **便携使用**：整个目录复制到任意位置（或 U 盘）即可带走全部数据
- **从旧版本升级**：如果本机存在旧版数据（`%LOCALAPPDATA%\MijiaProductGallery`），首次启动会自动把数据库、图片、缩略图、备份整体迁移到 `Data\`，迁移幂等、同名不覆盖，全部成功后才清理旧目录

## 操作指南

### 鼠标

| 操作 | 效果 |
|---|---|
| 左键点击卡片 | 查看产品详情 |
| 左键按住并拖出 | 拖拽原图到文件夹或支持图片的软件 |
| 右键点击卡片 | 打开操作菜单（复制 / 加入收藏 / 快速移除） |

### 键盘

| 按键 | 效果 |
|---|---|
| Ctrl + F | 聚焦搜索框 |
| ← / → 或 PageUp / PageDown | 上一页 / 下一页（分页模式） |
| Home / End | 第一页 / 最后一页 |
| Enter（页码框内） | 跳转到输入的页码 |
| Esc | 关闭筛选面板 / 对话框 |
| 菜单键 或 Shift + F10（卡片聚焦时） | 打开卡片操作菜单 |

## 同步与数据说明

- 产品数据来源为米家百科公开产品库（`home.mi.com`），应用以只读方式获取公开信息与示例样图
- 同步只更新官方数据列；**收藏、收藏夹、使用记录、搜索历史等用户数据与官方数据结构性分离**，任何同步操作都不会覆盖
- 同步进行时可在**同步中心查看实时进度**：当前阶段（获取分类 → 获取产品 → 对比数据 → 下载图片 → 更新数据库 → 生成缩略图）、计数百分比、已用时间与预估剩余时间
- 同步产生数据变化（新增 / 换图 / 下架等）后，图库筛选面板的分类与品牌自动刷新
- 图片与数据库均为本地文件，离线完整可用；联网仅在手动或自动同步时发生

## 从源码构建

```bash
dotnet build src/MijiaProductGallery.App -c Release
```

- .NET 10 LTS + Windows App SDK 2.5.x（WinUI 3，unpackaged + SelfContained）
- SQLite + EF Core · SkiaSharp（缩略图生成）· System.Text.Json · xUnit（412 项测试）
- `tools/SeedPackTool`：开发期把 [mijia-product-icons](https://github.com/iop666/mijia-product-icons) 数据快照转换成 `seed-<日期>.zip` 初始数据包
